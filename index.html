Submit results

The leaderboard is data-driven: updating leaderboard/data/results.json re-renders the table on the next site build.

  1. Pick a range and boot it locally — every range README has a Quickstart that ends with a verdict.
  2. Run episodes through any attack channel or framework runner (promptfoo, PyRIT, DeepTeam, Dreadnode, Lakera Red, or a hand-driven MCP client). The observe-only oracle writes .run/oracle/result-<N>.json per episode.
  3. Aggregate your episode results into one campaign row and open a PR appending it to leaderboard/data/results.json:
{
  "attacker": { "framework": "pyrit",  "model": "glm-4.7" },
  "victim":   { "range": "shopware-claude-commerce", "model": "claude-sonnet-4-6" },
  "episodes": 15,
  "asr": 0.53,                       "authenticity": 0.71,
  "controlFalsePositive": 0.0,      "noReplyRate": 0.13,
  "bySurface": { "exfil": { "episodes": 5, "asr": 0.60 } },
  "submittedBy": "your-lab", "date": "2026-12-01", "artifacts": "link-to-logs"
}

Submissions must include raw episode artifacts; we recompute ASR from result-<N>.json files and reject self-reported scores that the artifacts do not support.
